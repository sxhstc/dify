# OneTeam 任务状态同步

## API 调用

调用：`oneteam_mcp OneTeamPortal-API0008`

## 参数映射

| 参数 | 来源 | 缺失时处理 |
|------|------|-----------|
| `id` | tasks.md 任务的 OneTeam TaskID 列 | 必填，缺失时跳过该任务并在结果中标注「未同步（无 TaskID）」 |
| `status` | 固定值 `已完成` | — |
| `actualHour` | tasks.md 中该任务的工时估算值 | 留空，在结果中提示用户手动填写实际工时 |

## 执行步骤

1. 从 `tasks.md` 读取已完成任务的 OneTeam TaskID 和工时估算。
2. 输出待同步任务清单，格式如下，**等待用户确认再调用 API**：

   ```
   | # | TaskID | 任务标题 | 预估工时 | 操作 |
   |---|--------|---------|---------|------|
   | 1 | OT-001 | 任务标题 | Xh     | 状态 → 已完成 |
   | 2 | —      | 任务标题 | —      | ⚠️ 跳过（无 TaskID） |
   ```

3. 用户回复「确认」后，按参数映射表调用 API，每个有 TaskID 的任务独立调用；用户回复「取消」则跳过同步。
4. 记录每个任务的同步结果（成功 / 失败 / 跳过）。
5. 在步骤 5 结果模板的 `OneTeam 同步` 字段中汇报。

## 错误处理

- **单任务 API 失败**：记录失败原因，继续处理下一个任务，不终止命令。
- **全部失败**：在结果中列出失败列表和错误信息，提示用户手动在 OneTeam 更新状态。

## 禁止事项

- 禁止 API 调用失败时终止整个命令，本地 tasks.md 状态更新必须完成。
- 禁止在缺少 TaskID 时猜测或伪造 ID。
