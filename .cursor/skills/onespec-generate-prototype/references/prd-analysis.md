# PRD 内容分析规则

在生成原型前，深度解析 PRD 文档。

下表「原型组件」列名在 **Element UI 2** 与 **Element Plus** 中多数一致；落地时按 `package.json` 选择 **Vue2 + Element UI** 或 **Vue3 + Element Plus** 的写法（插槽、`$message` / `ElMessage`、`visible.sync` / `v-model` 等以 [html-template.md](./html-template.md) 为准）。

## 分析目标

提取三类信息，构成原型的数据和交互基础：

| 类型 | 提取内容 | 用途 |
|------|---------|------|
| **业务对象与字段** | 字段名、类型、必填项、校验规则、枚举值 | 表单字段 + 列表列定义 |
| **核心流程** | 状态流转、操作按钮、触发条件 | 状态标签 + 按钮交互逻辑 |
| **交互细节** | 弹窗/侧滑/抽屉、二次确认、动态显隐 | 组件选型 + 条件渲染 |

---

## 字段类型识别

按以下规则判断字段类型：

| PRD 描述关键词 | 推断类型 | 原型组件 |
|--------------|---------|---------|
| 填写、输入、文字 | `text` | `<el-input>` |
| 选择、下拉、可选（枚举值少于等于8个） | `enum` | `<el-select>` |
| 单选、二选一 | `radio` | `<el-radio-group>` |
| 多选 | `multi-enum` | `<el-checkbox-group>` |
| 日期、时间 | `date` / `datetime` | `<el-date-picker>` |
| 金额、数量、数字 | `number` | `<el-input-number>` |
| 开启/关闭、启用/禁用 | `boolean` | `<el-switch>` |
| 上传、附件、图片 | `file` | `<el-upload>` |
| 备注、描述、说明（多行） | `textarea` | `<el-input type="textarea">` |

## Few-shot 示例

### 示例 1：字段提取

**PRD 原文**：
> 审批记录包含：申请人（必填）、申请时间（自动）、审批状态（待审核/审核中/已通过/已拒绝，必填）、审批意见（非必填，最多500字）

**提取结果**：
```
字段列表：
- applicant:      text,     必填,    label="申请人"
- applyTime:      datetime, 自动填充, label="申请时间"
- approvalStatus: enum,     必填,    label="审批状态",
                  options=["待审核","审核中","已通过","已拒绝"]
- comment:        textarea, 非必填,  label="审批意见", maxLength=500
```

---

### 示例 2：状态流转提取

**PRD 原文**：
> 订单创建后为「待付款」状态；付款成功后变为「待发货」；商家发货后变为「待收货」；用户确认收货后变为「已完成」；任意阶段可取消，取消后状态为「已取消」。

**提取结果**：
```
状态列表：["待付款", "待发货", "待收货", "已完成", "已取消"]

操作按钮（按状态）：
- 待付款 → 按钮：[去付款（主）, 取消订单（次）]
- 待发货 → 按钮：[取消订单（次）]
- 待收货 → 按钮：[确认收货（主）]
- 已完成 → 按钮：无
- 已取消 → 按钮：无
```

---

### 示例 3：交互细节提取

**PRD 原文**：
> 点击「新建」按钮，弹出表单对话框，填写完成后点「提交」，二次确认后保存；删除前需确认，且仅「草稿」状态可删除。

**提取结果**：
```
交互模式：
- 新建 → 弹窗(Dialog)，表单提交 → MessageBox 二次确认
- 删除 → MessageBox 确认；仅 status==="草稿" 时显示删除按钮
```

## 分析输出格式

分析完成后，在**强制检查点**中输出以下摘要（填入 SKILL.md 要求的确认模板）：

```
核心模块：[模块名1, 模块名2, ...]
字段数量：N 个（列表字段 X 个 / 表单字段 Y 个）
状态流转：[状态1 → 状态2 → ...]（无则填「无」）
主要交互：[弹窗新建, 行内编辑, 侧滑详情, ...]
Mock 数据方案：[业务类型] + [3-5条高拟真数据示例]
```
