# AI 生成 Web 前端代码的基本要求

> 通用原则参考 `ai-workflow.mdc`。本文件仅补充前端特有约束。

---

## 组件与状态

- **逻辑与展示分离**：使用框架提供的复用机制（Hook / Composable）封装业务逻辑，组件只负责渲染
- **状态层级合理**：组件内部状态 → 跨层级共享 → 全局状态管理，按需选择，不过度提升
- **不可变更新**：状态更新必须产生新引用，禁止直接修改对象/数组

---

## 性能约束

- **大列表虚拟化**：1000+ 条数据必须使用虚拟滚动，禁止全量渲染 DOM
- **路由与大组件懒加载**：使用框架提供的异步加载机制，减少首屏体积
- **防抖节流**：输入搜索、窗口 resize 等高频事件必须防抖或节流
- **稳定 key**：列表渲染使用唯一业务 ID 作为 key，禁止使用数组 index

---

## 可访问性（强制）

- 使用语义化 HTML 标签（`<button>` 而非 `<div onClick>`）
- 图片必须有 `alt` 属性
- 交互元素支持键盘导航（tabIndex、onKeyDown）
- 自定义控件正确使用 ARIA 属性

---

## 错误处理

- 使用框架提供的错误边界机制捕获渲染异常，防止白屏
- 异步请求完整处理三态：loading / error / data
- 组件卸载时取消未完成的异步请求
